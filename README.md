# 🎣 Strat Fish

A modern digital marketing agency website designed to help businesses attract, engage, and convert customers through strategic digital marketing solutions.

🌐 **Live Demo:** https://starfiish.netlify.app

---

## 🚀 About The Project

Strat Fish is a performance-focused digital marketing agency website featuring a modern user interface, responsive design, and optimized user experience. The website is built to showcase services, generate leads, and strengthen online brand presence.

### Key Highlights

- Modern and responsive design
- Mobile-friendly experience
- SEO-focused structure
- Fast loading performance
- Professional agency branding
- Lead generation focused
- Cross-browser compatibility

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate to project folder:

```bash
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## 🏗️ Production Build

Build the project:

```bash
npm run build
```

Preview build:

```bash
npm run preview
```
